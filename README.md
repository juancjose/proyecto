# Imprenta Gráfica Espacio — Sitio web

Sitio web institucional de **Gráfica Espacio**, empresa de servicios de impresión. Proyecto del curso de Desarrollo Web de Coderhouse.

🔗 **Demo:** https://iridescent-dasik-21987e.netlify.app/index.html

## Sobre Gráfica Espacio
Gráfica Espacio se especializa en impresión de alta calidad:
- **Impresión offset:** para proyectos de alta calidad y grandes cantidades.
- **Impresión digital:** para tiradas chicas y entregas rápidas.
- **Impresión de gran formato:** colores vibrantes y duraderos.
- **Diseño gráfico:** ayuda para crear los diseños de cada proyecto.

## Contenido del sitio
- Inicio con carrusel de productos destacados y tarjetas de productos.
- Páginas: Productos, Ayuda, Contacto, Nosotros, Sublimación y Más info (`pages/`).
- Barra de navegación con buscador.

## Tecnologías
HTML5 · CSS3 · SASS/SCSS (compilado con `node-sass`) · JavaScript

## Cómo correrlo localmente
```bash
git clone https://github.com/juancjose/proyecto.git
cd proyecto
npm install
npm run build-css    # compila scss/style.scss -> css/style.css
# o: npm run watch-css  (recompila al guardar)
```
Después abrí `index.html` en el navegador.
